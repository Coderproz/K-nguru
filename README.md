# Känguru Math Quest (Grade 3-4)

تم تعديل التطبيق لعرض السؤال **كصورة** داخل الواجهة بدل عارض PDF.

## ما تم تنفيذه
- مكان السؤال أصبح صورة (`img`) داخل الواجهة.
- تمت إضافة ملفات صور أسئلة في: `assets/questions/`.
- يمكن استبدال الصور الحالية مباشرة بصور مقصوصة من PDF لكل سؤال.
- تم الحفاظ على: النقاط، التخطي، إعادة المتخطى، التلميحات، واللغات الثلاث.

## التشغيل
```bash
python3 -m http.server 4173
```
ثم افتح `http://localhost:4173`.

## استبدال الصور بصور الأسئلة الأصلية
1. خذ لقطة لكل سؤال من ملف PDF (قص السؤال فقط).
2. احفظها بنفس المسار/الاسم داخل `assets/questions/`.
3. أو عدّل خريطة `snapshots` في `app.js` لربط كل سؤال بصورته.
