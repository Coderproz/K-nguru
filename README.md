# Känguru Math Quest (Grade 3-4)

لعبة ويب تعليمية تعمل على المتصفح (Chrome/Edge/Firefox) لتدريب طلاب الصف الثالث والرابع بنمط مسابقة Känguru.

## الميزات
- واجهة ثلاثية اللغة: العربية / الألمانية / الإنجليزية.
- نظام نقاط مباشر.
- خيار تخطي السؤال مع إمكانية العودة للأسئلة المتخطاة.
- تلميحات تدريجية لكل سؤال (الحل غير مباشر لتشجيع التفكير الذاتي).
- قائمة بكل روابط ملفات السنوات 1998-2025 التي زوّدتني بها.

## التشغيل
```bash
python -m http.server 8000
```
ثم افتح:
`http://localhost:8000`

## ملاحظة مهمة بخصوص "كل التمارين"
تم تضمين **كل مصادر السنوات** داخل اللعبة، مع مجموعة أسئلة تدريبية بنمط كنغر قابلة للاستبدال.
لإدراج نص جميع التمارين الأصلية حرفيًا داخل `app.js`:
1. حضّر ملف JSON لكل سنة يحتوي نص السؤال والاختيارات والإجابة والتلميح بثلاث لغات.
2. استبدل `baseQuestions` بمحتوى السنوات الفعلي.
3. أبقِ نفس البنية:
```js
{
  points: 3,
  choices: ['A','B','C','D'],
  answer: 1,
  text: { ar: '...', de: '...', en: '...' },
  hints: { ar: ['...','...'], de: ['...','...'], en: ['...','...'] }
}
```
