# Känguru Math Quest (Grade 3-4)

لعبة ويب تعليمية تعمل على المتصفح لتدريب طلاب الصف الثالث والرابع لمسابقة Känguru.

## ما الذي تم تحسينه
- عرض **السؤال الأصلي من ملف PDF داخل واجهة التطبيق نفسها** عبر عارض PDF مدمج (iframe) مع تنقل الصفحات.
- دعم 3 لغات: العربية / الألمانية / الإنجليزية.
- نقاط فورية أثناء الحل + عداد محاولات.
- تخطي السؤال مع إمكانية الرجوع للأسئلة المتخطاة.
- تلميحات تدريجية غير مباشرة.
- إدراج جميع روابط ملفات السنوات 1998–2025.

## التشغيل
```bash
python3 -m http.server 4173
```
ثم افتح:
`http://localhost:4173`

## ملاحظة
- الآن الطالب يرى السؤال كما هو في PDF مباشرة داخل التطبيق (بدون فتح صفحة خارجية).
- إذا أردت مطابقة تلقائية دقيقة (كل سؤال ↔ رقم صفحة ↔ الاختيارات الرسمية)، يمكن توسيع `baseQuestions` في `app.js` ببيانات مفصلة لكل سنة.
